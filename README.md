# Student Supplies Ordering System

IT415 Midterm Practical Examination - Student Supplies Ordering System

A browser-based ordering application for a small school supplies shop near the campus. Customers can select supplies, manage quantities, see the total, enter a cash payment, and receive a digital receipt.

## Features
- Product list with six school supplies and prices
- Shopping cart with add, increase, decrease, and remove
- Automatic subtotal and total computation
- Cash payment with validation (blank, invalid, negative, and insufficient amounts)
- Automatic change computation
- Digital receipt with reference number, date and time, items, totals, amount paid, and change
- New Transaction button that resets the whole order

3. No installation, database, or login is required.
